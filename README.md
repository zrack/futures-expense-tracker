# Futures Trading Expense Tracker

A simple, offline-first web application for tracking prop trading expenses to help with tax write-offs.

## Features

- **Track Expenses**: Log all your futures prop trading related expenses with dates, amounts, and descriptions
- **Category Organization**: Pre-configured categories for common trading expenses:
  - Evaluation Fees
  - Account Fees
  - Data Subscriptions
  - News & Research Subscriptions
  - Educational Materials
- **Summary Dashboard**: View total expenses and breakdown by category at a glance
- **Export to CSV**: Download your expense data as CSV for tax preparation or accounting software
- **Offline Storage**: All data is stored locally in your browser using localStorage
- **No Backend Required**: Completely standalone HTML file - no server or database needed

## Getting Started

### Installation

1. Download the `futures-expense-tracker.html` file
2. Double-click the file to open it in your web browser
3. Bookmark the page for easy access

That's it! No installation, dependencies, or setup required.

### Usage

1. **Add an Expense**: Fill out the form with:
   - Date of the expense
   - Category (select from dropdown)
   - Amount in USD
   - Description (e.g., "TopStep Challenge Fee")
2. **View Totals**: See your total expenses and category breakdowns in real-time
3. **Export Data**: Click "Export CSV" to download your expense data for tax records
4. **Delete Entries**: Click "Delete" on any expense to remove it

## Data Storage

- All data is stored locally in your browser's localStorage
- Your expense data never leaves your computer
- Data persists between sessions as long as you use the same browser
- To backup your data, use the "Export CSV" feature regularly
